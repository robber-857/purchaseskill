# 品类与用途适配

这些是需调查的维度，不是对某产品现行法律义务的断言。先确认采购用途和地区，再从当前官方来源确认实际要求。

| 场景 | 主要比较方法 | 需额外确认 |
| --- | --- | --- |
| 零售/经销 | 单位贡献、商品组合增量、周转与现金占用 | 同款规格、价格带、退货、渠道限制、变体SKU |
| 食品/易腐品 | 每个可销售单位成本与效期内售罄情景 | 原料/过敏原、批次追溯、储运温度、到货剩余效期、适用准入 |
| 原料/工业耗材 | 单位合格产出成本、良率与供货中断风险 | 公差、样品/批次检验、兼容性、替换验证、MOQ |
| 设备/电器 | 同周期TCO、产能及停机风险 | 安装、供电、维护、耗材、备件、使用培训、保修、适用安全要求 |
| 儿童用品/玩具 | 用途适配、耐用性与适用安全证据 | 年龄分组、材料、小部件、警示、对应型号检测；宣传不能替代检测 |
| 服饰/家具 | 规格、尺寸覆盖、耐用性、物流和退换货 | 变体名额、材料、试用/试穿、包装体积、售后 |
| 化学品/医疗相关 | 先确认用途分类与专业验收路径，再进行商务比较 | 适用范围、资料、储运、资质、样品检验、专业责任；缺项保留待审 |
| 软件/订阅 | 按席位/用量及期限计算TCO和迁移成本 | 许可范围、数据/接口需求、续费价格、服务水平、退出与数据导出 |

原料常见公式：每合格单位成本 = 本批总相关成本 ÷ 合格产出。必须确认投入与产出的单位及转换率，不能把重量单价和件单价直接对比。

设备/软件的收益需单列依据（例如工时、停机损失、产能利用），没有证据只比较成本与需求覆盖。现金支出与折旧、残值不要重复计入同一口径。

新品/新设备替代建议应包括过渡安排：试销/试用、停补、消化、调拨/退供、迁移/退役。不能从“相似度高”直接推出应该清退。
