# 选品有据 · Purchase Review Demo

面向中国国内采购的交互式新品评审演示。用真实产品资料和明确标注的模拟经营数据，演示产品准入、SKU重叠、收益情景以及内外两份报告。

## 立即演示

下载或克隆仓库，双击 `index.html`，或在 Windows 双击 `打开演示.cmd`。无需安装网页运行依赖。使用 Chrome / Edge。公开仓库只包含源码、模拟数据与说明，原始图片和PDF保留在本地，不随源码发布。

完整本地演示包已包含素材。仅克隆源码时，图片区域会显示缺失说明；使用自己的附件补齐本地素材：

```powershell
python -m pip install pymupdf
python prepare_assets.py --bkt-image "你的产品图.jpg" --warmies-pdf "WARMIES BRAND BOOK 2024-2025.pdf"
```

此导入脚本针对本次品牌册的第22、30页布局，不是通用文件解析或AI识图功能。`assets/` 已在Git忽略列表中。

也可执行 `python server.py`，访问 `http://127.0.0.1:8150`。

## 三个商品

- BKT 护腰坐姿椅：用户提供的产品宣传图片。
- Warmies 长毛绒企鹅：2024–2025品牌册第22页，按造型命名，正式型号待确认。
- Warmies 小型蓝色龙：同品牌册第30页，按造型命名，正式型号待确认。

产品素材版权属于相应权利人。公开仓库不分发用户提供的原始附件或从附件提取的图片。

## 已实现

三商品切换、原始资料查看、实时采购参数调整、三情景与盈亏平衡计算、资料准入假设开关、模拟SKU对比、双报告预览及独立HTML导出、演示引导、响应式布局。

供应商导出通过白名单数据和固定模板生成，不包含内部经营参数、库存、计算脚本。整个演示网站本身包含模拟内部数据；对供应商分享时只发送单独导出的供应商报告。

## 当前范围

这是可操作的静态演示前端，尚未接入 OpenClaw Skill、实时 AI/联网搜索、真实库存或文件上传解析。所有价格、销量、库存及利润为演示假设。附件中的品牌认证及性能声明未独立核验，不构成中国市场准入判断。
