# 采购报告 UI · 2026-11-08

视觉主张：纸白工作区、深绿导航和克制的分隔线，用明确的字级与留白突出采购结论。

内容顺序：采购建议与评分 → Overview 四个决策问题 → 评分依据 → 收益/风险与情景 → SKU 影响与退出条件 → 证据 → 补件行动。

交互主张：报告轻量入场；侧栏定位章节并同步阅读位置；受众切换清晰过渡，供应商视图只渲染独立白名单对象。尊重减少动态效果设置。

参考（布局借鉴，不复制素材）：
- https://dribbble.com/shots/25709086-Sidebar-navigation-Untitled-UI
- https://dribbble.com/shots/7643735-Filepro-Dashboard

评分是采购决策的资料支持度，不是商品品质认证或自动审批。五维加权，缺项记为未获得分数并显示原因；基础整理及未包含结构化评估的历史报告不自动推导分数。利润只由完整、同币种同周期、带来源的输入计算，缺数不补零。对非转售用途，不套用 SKU 清退与零售贡献模型。
