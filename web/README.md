# 选品有据：上传与资料评审

独立于根目录旧模拟演示的新应用。支持本机运行、Vercel 接口与前端、Supabase 私有存储与报告分享。

## 现在可以做什么

- 无需账号即可本地上传、解析 Excel（XLSX / XLS）/ UTF-8 CSV / PDF / PPTX / PPT / JPG / PNG / WebP / DOCX / UTF-8 TXT，查看页面来源。
- 没有模型密钥：生成明确标记的「基础整理」报告，只含原文摘录与通用补件要求，不冒充产品语义分析。
- 配置视觉模型：执行实际 purchase-review Skill 与参考规则，生成结构化 AI 初筛，保留文件/页码和未知项。没有联网搜索，不能声称已核验品牌声明。
- Warmies 真实附件案例单独预先审阅：`/example/warmies`。47 页缩略图通览，第 4、22、30 页放大审阅，未使用旧演示的模拟经济数据。
- 未配置模型时，上传原始 Warmies PDF，服务器核对 SHA-256；文件完全一致且市场为「中国」、用途「转售商品」、重点备注为空时，复用已审阅报告，并明确标注缓存来源。配置模型后，新上传文件（包括 Warmies）均实时调用模型；已保存案例仍可单独查看。不同文件或不同评估场景不会套用案例结论。
- 报告独立下载 HTML / 浏览器另存 PDF；可创建 7 天分享链接并撤销。供应商版使用固定白名单模板，完全不传递内部模型内容。

## 决策报告与评分（2026-11-08 更新）

客户默认查看简明决策摘要：采购建议、产品与价格、最多3项重点问题、现有商品影响及下一步。每条重点讲清事实、对采购的影响与建议动作，使用日常中文；不因缺少价格而编造“贵/便宜”的判断。完整评分、证据、风险与计算移入默认折叠的附录。默认PDF只打印摘要，展开附录后可一起打印。AI生成规则和独立Skill已同步；历史报告没有简报字段时保留原结论并提示重新生成，不自动猜测重点或价格。

- 侧栏按“决策总览 → 价格与产品 → 关键问题 → 现有商品影响 → 下一步 → 详细依据”定位，正文使用同一页面滚动；手机保留常驻受众切换与导出。
- 首屏显示采购建议和辅助评分，正文突出价格、最多三个重点及行动建议。建议区分暂缓采购、进入样品评估和不建议采购，评分不自动批准采购。
- 评分衡量**采购决策的资料支持度**，不是商品品质评级：产品与需求 20%、质量与使用条件 25%、商务与交付 20%、组合适配 15%、收益成本 20%；各项无/部分/较完整依据分别取得权重的 0%/50%/100%。展示给分理由与来源。
- Warmies 已审阅案例为 **23/100**（两个部分依据维度、三个资料缺口），是两款候选的共同初筛范围，不是分别测得的产品质量分。基础整理不评分；历史报告无 `assessment` 时显示暂未评分，重新生成才会补充新字段。
- 新 AI 报告包含结构化评分、潜在收益、SKU 对照与退出条件。有完整同币种/同周期输入时，展示保守/基准/乐观三情景，程序扣除变动成本、旧品贡献损失、上新/退出及仓储资金成本。缺数不补零；非转售用途不套用这个模型。
- SKU建议区分暂停/减少补货与未来替换；有依据的当前库存动作直接写在简报中，不因新品仍需验样而一律写“待核验”。建议不自动执行订单取消或商品下架。
- 内部/供应商视图可直接切换，HTML 下载和 PDF 打印只包含当前版本。供应商仍为独立通用补件模板，不自动传出内部理由、分数、型号清退名单或底价；分享默认选择供应商版。
- 独立 Skill 的报告规则已同步；图文资料的网页检索、真实 ERP 接入与采购执行不属于本次 UI 更新。

## 供应商资料与内部经营数据（2026-11-08）

- `/` 是供应商资料入口；`/internal-data` 是独立导航的内部经营数据页，支持上传、解析预览、选择用于评审及移除。
- 内部原文件通过 IndexedDB 保存在当前浏览器，刷新后可复用；不跨设备同步，不构成共享企业 SKU 数据库。移除仅清除浏览器副本，不删除已生成的历史任务。
- 首页显示已选内部文件。生成时将供应商文件与已选内部文件一起上传私有存储，并以 `supplier` / `internal` 角色传给模型。未勾选的内部文件不上传、不参与本次评审。
- 两类文件合计最多 6 份、100 MiB、80 页/片段；单文件默认 50 MiB。取消的是每日任务数和累计存储预算，不改变单次处理能力。
- 两个入口均支持 `.xlsx` / `.xls` / `.csv`。表格保留工作表名、原行号及单元格地址，分片重复首个非空行供表头核对；UTF-8 CSV 保留前导零，Excel 保留显示格式，空白不补零。
- 不执行公式、宏或外部链接；公式只使用文件已有缓存值（可能过期），缺失值标为未知。隐藏工作表会纳入并标注，合并单元格不自动填充。表格图片、图表、批注不读取。每表最多 10000 行/100 列，超过片段或单行文本上限会明确拒绝，不静默截断。
- 页面提供 `public/templates/sku-template.xlsx` 与 UTF-8 `sku-template.csv`。模板为空白输入表，不包含模拟库存；Excel 另带填写说明。
- 供应商反馈仍使用独立白名单模板，不包含内部经营数据、原始文件或内部分析。

## 本地启动

Node.js >= 22.12（推荐 24）。从当前目录运行：

```powershell
npm install
npm run dev
# http://127.0.0.1:8151
```

也可以双击项目根目录的 `启动资料评审.cmd`。首次安装需要网络。

正式演示更适合 `npm run build` 后 `npm start`，避免开发服务器首次加载解析依赖时自动刷新。

默认本地数据在 `web/.local-data`，被 Git 忽略。只绑定 127.0.0.1；本地分享链接只能在此电脑打开，不是公网链接。新文件解析在浏览器完成；生成时才上传原件、页面文字与图像。原件、提取内容和生成报告均不出现在公开静态资源目录。

## 可用格式与真实限制

| 格式 | 实际处理方式 | 限制 |
|---|---|---|
| Excel / CSV | 按工作表与行列提取显示值 | 不读图片、图表、批注；不执行公式；CSV 需 UTF-8 |
| PDF | 逐页提取文字并渲染图像 | 扫描件需要视觉模型/人工；加密/损坏文件报错 |
| PPTX | 按演示文稿顺序提取文字与每页最多 3 张嵌入图片 | 不恢复整页版式、图表、SmartArt、母版、备注、动画；遗漏会标注，完整视觉评审建议导出 PDF |
| PPT | 提取旧二进制文字记录 | 不保证页序，可能含历史文字，不读取图片；来源标为片段，完整评审建议另存 PDF/PPTX |
| JPG/PNG/WebP | 缩放后提供给视觉模型 | 长边最多 1400 像素；细字需原件复核 |
| DOCX | 正文文字分片 | 不含图片、页眉页脚、修订与原始页码 |
| TXT | UTF-8 文字分片 | 不含原始页码 |

默认单文件 50 MiB，总计 100 MiB，最多 6 个文件、80 页/片段。页面图像加提取文字总量最多 16 MiB。超过上限明确报错，不静默跳过后半份文件。每页文字最多 14000 字符，若截断会记录限制。

`MAX_FILE_MB=100` 可启用 100 MiB 单文件，本地支持；Supabase Free 单文件硬上限 50 MB，升级套餐并修改项目全局及 bucket 上限后才能使用 100 MB。代码参数不能改变托管服务限制。

## Vercel + Supabase 接入

1. 新建 Supabase 项目，在 SQL Editor 执行 `supabase/schema.sql`。得到私有 `review-private` bucket、`review_jobs` 表与任务创建兼容函数与并发控制函数。不要给 `anon`/`authenticated` 添加公开表或存储策略。
2. 在 Vercel 导入此仓库，把 Root Directory 设为 **web**。构建命令 `npm run build`，输出目录 `dist`；`vercel.json` 提供 API 路由。
3. 参考 `.env.example` 设置服务端环境变量：`SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`、`DEMO_INVITE_CODE`。后者设置为向受邀试用者提供的邀请码；修改后需重新部署生效，不写入公开仓库。密钥不得使用 `VITE_` 前缀，不进入前端。
4. 选择支持图片与 JSON 模式的 OpenAI 兼容模型，设置 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`。未设置时仅提供基础整理。此版本使用 `/chat/completions`、`response_format:json_object`、`max_completion_tokens`，兼容性需用所选服务实际验证。
5. 再部署并上传一份文件，验证 Supabase 对象、任务完成、分享可读、撤销后不可读。当前生产实例已接通 Supabase 与 GPT-6 Luna，详细验收范围见 `VALIDATION.md`。

模型与服务地址由服务端环境变量配置，报告保留实际模型、用量及请求 ID。实际费用以模型服务账单为准；部署前后应使用新的上传任务验证生成结果。

浏览器直接上传 Supabase，超过 6 MiB 使用带签名 token 的 TUS 分块上传，不经过 Vercel 4.5 MB 请求体。服务器只接收任务元数据与生成指令；服务端下载解析 manifest 后调用模型。没有配置 Supabase 或邀请码时，Vercel 上拒绝新建任务，案例和本地文件解析仍可查看。

每次任务最多一次并发模型调用，失败不会伪装为成功或自动降级，最多 3 次显式尝试。单次模型请求超时 220 秒，Vercel函数上限配置 300 秒。生成期间保持页面打开；刷新后用「恢复上次任务」，异常锁 10 分钟后失效。暂不提供后台队列或 SLA。

## 任务数量与服务容量

- 对方不付费：已有案例不调用模型；新上传文件可使用基础整理，或由站点所有者支付模型费用。
- Supabase Free：1 GB 文件存储、500 MB 数据库、单文件最大 50 MB；少量演示够用。应用不再限制每日任务数量或累计预留存储预算；每任务仍记录原件大小 + 16 MiB，供容量统计参考。
- 原文件 12.2 MB 的 Warmies 不能按 1 GB 简单计算 80 份，因为还会保存页面图像和其他资料。每个任务记录的预估空间包含解析内容。
- Vercel Hobby 限个人非商业用途；面向客户的商业演示应选择适用计划，不因为访客免费就等于托管合规免费。
- Supabase 免费项目闲置 1 周可能暂停；正式演示前应检查服务状态。
- 邀请码不等于强身份认证。适合少量受邀试用；公开大规模开放前应增加账号、滥用保护及更严格上传配额。
- 应用已移除 `DAILY_JOB_LIMIT` 和 `STORAGE_BUDGET_MB` 配置，旧环境变量即使保留也不再生效。云端直接通过服务端私有连接创建任务，不再调用旧的额度检查函数；已有 Supabase 项目无需迁移即可使用新版应用。
- 单文件、单次上传和解析页数限制仍然有效；实际存储容量、模型余额与托管服务限制由服务商决定。签名上传后会核对实际大小。

本版没有自动删文件：数据留在私有存储供复核。管理员按需在 Storage 删除任务 UUID 目录下的 source-N 与 manifest.json，再删除对应 review_jobs 行即可清理任务记录与存储；删除前导出需要保留的报告。分享过期只停止访问，不删除原件。清理时应等待签名上传链接到期，避免未完成上传重建对象。

## 验证与部署素材

`npm test` 覆盖任务权限、上传与报告流程、分享失效/撤销、供应商隔离、XSS 转义、50/100 MB 边界、模型失败和并发。模型相关自动测试使用本地模拟 HTTP 服务，不证明真实模型或 Supabase 云端已经接通。

`npm run build` 验证生产构建。`npm run sync-skill` 从仓库根目录的规范 Skill 同步执行规则副本。

`public/demo-assets` 是本地生成的 Warmies 案例少量页面与产品预览，被 Git 忽略；不上传原始整本 PDF。新克隆时可运行 `python scripts/prepare_demo.py`（需 PyMuPDF，仓库本地 .runtime 已有）从用户持有的原册重建。缺少素材仍能阅读文字报告。
