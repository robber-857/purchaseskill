# 采购报告与展示页优化方案

采购人员打开报告时，首先需要决定这次采购能否推进，以及今天该向谁要什么。供应商收到报告时，首先需要知道优先讨论哪几款，以及怎样提供一份可以继续评估的回复。

## 两种报告怎样读

| 阅读位置 | 采购人员看到什么 | 供应商看到什么 |
| --- | --- | --- |
| 首屏 | 评估对象、日期、市场、采购建议及依据，旁边给出现在先做的一件事 | 候选产品名称和本轮合作建议，直接进入报价、选款、样品或回复清单 |
| 做决定 | 优先阅读影响最大的几个问题，每项说明影响和建议动作。没有重点摘要的历史报告展示已有风险 | 按型号分列供货报价、建议零售和适用条件，可展开核对报价原文 |
| 看产品 | 按优先评估、第二阶段、暂缓、待确认排列，逐款写明角色、理由和推进条件 | 按送样、先补资料、第二阶段讨论分组，附可确认的供应商产品图和具体要求。新报告可列有来源的合作机会 |
| 对照市场 | 1688 和淘宝候选保留商品来源；核对规格、价格、计价单位、起订量和税运后再作采购比较 | 只使用供应商材料中的公开报价和说明 |
| 收尾 | 对现有商品的影响、按类补件、推进步骤。需要复核时展开评分、风险、成本测算及证据页码 | 逐款回复规格和样品要求，再确认商务条款、交付安排和下一步 |

例如，Warmies 案例首页先提醒采购人员，两款毛绒玩具的正式型号、到货报价及加热说明仍待确认。读者可以直接跳到补件清单，把这些问题发给供应商。查证产品造型时，再打开对应的品牌册页面。资料不足时保留未知金额。

## 页面与封面

- 保留工作台现有绿色与导航。内部报告首页用较大的采购结论搭配简短行动说明，评分移入可展开的详细依据。报价和证据引用放在相关结论旁，降低来回查找的次数。
- 桌面横排对照报价。窄屏按商品拆行为带字段名的纵向清单，产品、供货价、建议零售和条件可在一屏宽度内连续阅读。小屏提供章节快捷入口。
- 联网候选优先使用对应商品页面或同商品检索结果的图片。同款图片有多个来源地址时保留备选。无可用商品图时用标明缺图的来源封面，用户仍可查看商品链接。供应商报告的产品图只来自对应的供应商资料。
- 网页、下载的 HTML 和打印共用同一报告。打印时隐藏工具栏和快捷入口。内部附录随展开状态打印，报价表保留列标题。外部图片的可用性取决于原站。

## 用户能看到的文字

| 场景 | 页面应回答的问题 |
| --- | --- |
| 文件只能提取部分内容 | 哪些内容可以阅读，是否需要补充清晰原件 |
| 只有公开搜索摘要或页面需要登录 | 价格能否作为参考，接下来应打开哪个商品链接或补哪张截图 |
| 找不到图或图片失效 | 商品来自哪个平台，在哪里核对原图 |
| 分析或保存失败 | 哪一步失败，现有结果是否可继续使用，用户可以怎样重试 |
| 复核报告 | 依据来自哪个文件、哪一页、哪些声明仍待确认 |

业务页面保留型号、币种、计价单位、日期、资料出处等影响判断的信息。服务返回的错误、模型编号、规则版本等技术细节从阅读和导出路径移除。历史记录按相同的展示规则呈现。

## 验收口径

1. 打开历史案例，首屏能回答当前建议和下一步，评分只在详细依据中出现。点击引用能核对相应资料。
2. 检查正常商品图、首选地址失效、全部地址失效以及没有图片的商品。每种情况下都能识别商品来源并打开原链接。
3. 在手机、平板和桌面分别阅读报价与样品要求，检查标签、按钮、换行和整体横向溢出。
4. 检查内部与供应商视图、分享页和下载 HTML。供应商版本只含允许对外展示的内容；打印件保留当前报告的表头、建议和行动清单。

## 本地验证结果

- 真实检索“304 不锈钢保温杯 500ml”时，1688 未返回可展示的单品，淘宝返回两条线索。一条跳转被排除，另一条从商品页补回主图，浏览器成功显示 800 × 800 图片。
- 对照测试覆盖首选图可用、首选图失效后显示备用图、所有图片失效以及缺少图片地址。检查了网页、独立 HTML 和打印样式。
- 在 320、390、768、1440 像素宽度检查了报告导航、表格和分享阅读界面，未发现整页横向溢出。三份不同内容的验证报告共打印 7 页 A4，没有空白页。
- 使用一份明确标记为模拟的单品报价实际生成供应商报告，报价保留模拟标记，并输出了有来源的合作机会及产品合规、商务供货两组待办。
- HTML 导出按钮生成的文件内容已保存，并以独立文件重新打开。自动化浏览器触发原生下载后返回取消；同环境中最小测试文件也出现相同行为，原生下载落盘仍待实机确认。

## 两份报告的布局复查

| 实际阅读场景 | 调整与验证 |
| --- | --- |
| 平板切换内部评审和供应商反馈 | 768 像素宽度下收起桌面侧栏，保留一套工作台导航和报告切换按钮。跳转到报价章节时，标题与吸顶工具栏之间留 12 像素。横屏高度较低时，工具栏随正文滚动。 |
| 手机上核对内部报价和成本 | 市场比价按商品显示字段，成本按项目并列三个情景。使用模拟报价和成本数据复测，320 像素宽度下原先两张表都需横移 247 像素，调整后均可在当前宽度读全。 |
| 供应商核对报价和样品要求 | 依据正文可用宽度切换表格与逐款清单。长报价条件、依据和样品要求可以使用整行宽度。有图和无图的产品卡分别按内容收尾。茶品样例展开全部报价依据后，在 320 至 1440 像素的七种宽度下均可读全。 |
| 打印和离线阅读 | 从网页导出 Warmies 内部评审，分别打印正文与展开附录的版本，得到 2 页和 5 页 A4。离线茶品供应商反馈打印为 3 页 A4。检查了全部 10 页的内容、边界与分页。 |

参考资料为用户提供的《Umall Purestic / TenRen 供应商版》第 1 至 3 页，以及当前项目的[双报告与交付规范](https://github.com/robber-857/purchaseskill/blob/main/skills/purchase-review/references/reports.md)和[工作台设计说明](https://github.com/robber-857/purchaseskill/blob/main/DESIGN.md)。样稿的商品、价格和合作判断仅用于理解版式，自有报告按本次采购资料填写。
